# Codvio — AI App Builder & Coding Agent

**Codvio is an AI coding agent that runs on your Android phone.**
Just write a prompt — Codvio writes and edits real code directly inside your project folder, on your device. No computer needed.

## ✨ Features

- **Bring your own API key** — works with 200+ AI providers, plus custom OpenAI / Anthropic-compatible endpoints and local models (Ollama / LM Studio)
- **Multiple keys, zero interruption** — add several keys per provider; Codvio switches automatically when one hits its limit
- **Real on-device tools** — reads, writes and edits files, runs commands, searches the web, and connects to MCP servers
- **Your files stay yours** — everything happens inside the project folder you choose, on your phone. Nothing is uploaded anywhere
- **Plan mode & Build mode** — let the agent make a plan and approve it first, or let it build directly
- **You stay in control** — Codvio asks permission before editing files or running commands, and every change can be undone
- **Skills** — built-in skills included, and you can import your own skills from GitHub or from a file
- **Background sessions & voice input** — long tasks keep running while you do other things
- **Meet Vio** 💜 — a friendly floating companion who reacts while the agent works

## 🪜 Full Setup — Step by Step (for beginners)

**Step 1 — Install the apps**
Install Codvio (from the Releases page above), Code On The Go and HopWeb (links above).

**Step 2 — Create your project**
- For an **Android app**: open **Code On The Go** and tap **New project**. A list of templates will appear — select **Compose Activity** (this is important, because Codvio builds modern Compose apps). Then fill in your app's name and tap **Create**. (If your project already exists, just open it.)
- For a **website**: open **HopWeb** and create your project there.

**Step 3 — Connect Codvio to the SAME folder**
1. Open **Codvio** and finish the one-time setup (allow Storage, Notifications and Background permissions).
2. Add your AI provider's API key in **Settings → Providers**.
3. Start a new session and **choose the same project folder** you created in Step 2.
   👉 Codvio edits that very folder directly — nothing is copied or moved. Whatever Codvio writes, the other app sees instantly.

**Step 4 — Build with a prompt**
Write what you want in plain words, like *"Build a fitness app with a home screen and a workout timer."* Codvio's agent creates and edits the files for you. If it asks permission to edit a file or run a command, tap **Allow**.

**Step 5 — Make the APK**
1. Open **Code On The Go** — your project is already there, with all of Codvio's changes.
2. Tap **Build / Run** and wait for the build to finish.
3. Install the APK it creates — your app is ready! 🎉

For **websites**: open the same project in **HopWeb** to see your site live.

💡 **Tip:** If something doesn't work, just tell Codvio in the same session what is wrong — it will check and fix its own work.
